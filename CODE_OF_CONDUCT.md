# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1 as its code of conduct.

All contributors, maintainers, and participants are expected to abide by its terms when interacting in this project's spaces (issues, pull requests, discussions).

## Enforcement

Report unacceptable behavior to **manoj.elumalai@outlook.com**. All reports will be reviewed and investigated promptly and fairly.
