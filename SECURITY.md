# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Report privately via [GitHub Security Advisories](https://github.com/manojelumalai/agentic-workflow-engine/security/advisories/new) or email **manoj.elumalai@outlook.com**.

We aim to acknowledge reports and provide an initial response within **5 business days**.
